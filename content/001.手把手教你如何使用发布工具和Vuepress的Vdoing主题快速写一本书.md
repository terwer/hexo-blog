# 001.手把手教你如何使用发布工具和 Vuepress 的 Vdoing 主题快速写一本书

全程一键操作，方便省心。您可以专注于您的内容创作，告别繁琐的重复工作 。

‍

## 准备工作

* 思源笔记 v2.10.15
* 安装 发布工具 插件
* 准备好 Vueress，并使用[ Vdoing 主题](https://doc.xugaoyi.com/)

## 开始写作

这里只需要 **遵循几个简单的约定 ** 即可。

* 标题用 `数字`​​​+`.`​​​ 开头。
* 每一级标题需要有序号，序号从 000 开始，并且递增，不能重复。
* 章节之间直接使用文档树，下一步一键发布的的时候会自动映射。
* Github 的标题不允许有空格，所以这可能是一个不太友好的地方，建议空格用 `_`​ 或者 `-`​ 代替。注：Gitlab 支持空格。

例如：

![image](assets/image-20231119100051-uadcm1h.png)

## 一键发布

直接一键发布到 GitHub。

唯一需要注意的是发布工具配置的发布路径应该是 `docs/[auto]`​，文件规则是 `[filename].md`​.

## 自动部署

GitHub 配合 Vercel 可实现全自动化部署。
